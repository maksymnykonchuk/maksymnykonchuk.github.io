# Портфоліо Максима Никончука

Сайт на React, Vite і Tailwind CSS. Українська версія доступна за `/`, англійська за `/en/`. Збірка записує готовий HTML і CSS у `dist/`. Навігація й деталі проєктів працюють через нативні елементи браузера.

## Локальний запуск

Потрібен Node.js 20.19+ у гілці 20 або Node.js 22.12+. Запустіть із директорії проєкту.

```sh
npm ci
npm run dev
```

Відкрийте адресу, яку покаже Vite. Щоб перевірити готову збірку, виконайте такі команди.

```sh
npm run build
npm run preview
```

## Публікація на GitHub Pages

У репозиторії `maksimnykonchuk/maksimnykonchuk.github.io` відкрийте **Settings → Pages → Build and deployment → Source** й виберіть **GitHub Actions**. Workflow `Deploy to GitHub Pages` збирає сайт і публікує `dist/` після оновлення гілки `main`. Для першого запуску після налаштування Pages можна вибрати **Actions → Deploy to GitHub Pages → Run workflow** і вказати `main`.

## Оновлення вмісту

### Фото та метадані

Додайте власне фото до `public/images/`. У `src/content.js` задайте `site.portrait` як об’єкт із полями `src` (шлях від `/images/`), `width`, `height` і `alt` з описами для ключів `uk` та `en`. За потреби додайте `position` для кадрування, наприклад `'center 35%'`. Коли `portrait` дорівнює `null`, на широкому екрані показується монограма.

Задайте остаточний HTTPS-домен у `site.url` і повторіть збірку. Це заповнить canonical, hreflang, `og:url` і повні адреси двох локалізованих Open Graph-обкладинок. Обкладинки можна замінити через `site.socialImage.uk` та `site.socialImage.en`, вказавши `src` і `alt`.

### Кейси

Кейси редагуються в `src/data/projects.js`. Для кожного проєкту збережіть зображення в `public/images/` і додайте їх до `screenshots`. Для кожного вкажіть `src` (шлях від `/images/`), оригінальні `width` і `height` та `alt` (об’єкт `{ uk, en }`). Перший запис стає обкладинкою, наступні 2–4 відображаються в галереї в розділі «Деталі проєкту». Натискання відкриває зображення у вікні перегляду. Довгий скриншот можна прокручувати, а кнопка «Оригінальний розмір» дає змогу роздивитися деталі.

Параметр `preview: 'wide-top'` показує верхню частину скриншота у форматі 16:9. При натисканні відкривається повний файл із `src`.

Щоб показати публічне посилання, додайте `link` із полями `href` та `label` (об’єкт `{ uk, en }`). Для M_Cargoo можна вказати репозиторій, якщо публікацію коду дозволено.

### Контакти

У `src/data/contacts.js` задайте `value` для відображення та `href` для переходу. Для пошти використайте `mailto:`, для Telegram і GitHub — повні адреси з `https://`. Показуються записи з обома заповненими полями. Кнопка «Обговорити проєкт» відкриває Telegram, якщо він налаштований.
